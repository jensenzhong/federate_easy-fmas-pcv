本研究的方法论主线围绕实验 C 展开，其核心目标不是在集中式数据条件下追求单次训练的最优拟合，而是在原始项目数据不能跨区域直接共享的约束下，构建一个能够持续协同学习、动态调参并具备过程解释能力的联邦造价预测框架。整体设计借鉴了 Zhang et al. (2023) 在高速公路项目造价预测中对数值型工程变量、经济指标和目标变量幂变换的处理思路，但结合本文的数据分布特征与研究目标，对数据组织方式、模型训练机制和调参逻辑进行了联邦化与智能体化改造。

4.1 Data数据处理和特征选取

本研究使用的原始数据来自佛罗里达州高速公路项目数据库。在完成缺失值筛查、字段统一和异常记录排除后，最终保留 688 条有效样本。选择这一数据源的原因有两点：其一，该数据集同时包含工程项目属性与宏观经济信息，能够支持成本形成机理的多维刻画；其二，7 个行政区之间在项目规模、市场竞争程度和区域经济条件上存在天然差异，这种差异为构造联邦学习中的非独立同分布场景提供了现实基础。

与 Zhang et al. (2023) 优先使用连续型变量进行建模的思路一致，本文仅保留可稳定量化且在各区域间具有一致统计含义的数值特征。具体而言，输入变量共 10 个，其中 6 个为项目层面的工程特征，包括投标人数 BIDS、承包商绩效评分 CPPR、合同工期 ContDays、项目长度 LEN、车道数 LANE 和天气影响天数 WeatherDelayDays；其余 4 个为宏观经济指标，包括 CPI、ContSpend、PLR 和 PPI。之所以采用这 10 个变量，是因为它们一方面覆盖了项目规模、施工复杂度、竞争环境和外部经济条件等主要影响因素，另一方面均可在不同客户端之间保持统一量纲，适合进入联邦模型进行参数聚合。区域标签和其他高离散或高缺失字段未被作为输入特征使用，是为了避免模型直接学习“数据来源”这一捷径信息，或因离散变量在小样本条件下引入额外波动。

为了让联邦场景尽可能贴近真实的多机构协同环境，本文没有对 688 条样本进行随机均匀拆分，而是按照地理邻近性和样本规模均衡性将 7 个行政区重组为 3 个客户端。具体划分为：Client 1 对应第 4、6、7 区，共 233 条样本；Client 2 对应第 2、3 区，共 235 条样本；Client 3 对应第 1、5 区，共 220 条样本。这样划分的关键原因在于，若仅按随机方式平均分配样本，各客户端的分布会过于相似，联邦训练会退化为近似独立同分布的普通分布式训练，从而削弱聚合策略和智能体调参的研究意义；相反，保留区域差异后，联邦模型必须在“跨区域共享规律”和“局部区域特征”之间取得平衡，这才构成实验 C 的核心研究问题。

在特征预处理方面，本文没有采用各客户端独立标准化，而是实现了隐私保护的联邦 StandardScaler。具体而言，每个客户端仅计算并上传本地特征矩阵的求和值、平方求和值和样本数，中央服务器据此聚合出全局均值和全局方差，再将统一的标准化参数回传给各客户端执行局部变换。这样做的原因不是单纯为了节省通信量，而是为了保证所有客户端进入神经网络的输入空间具有相同的尺度。若每个客户端独立标准化，则相同的模型参数在不同客户端上将对应不同的统计语义，服务器端即使完成了参数加权平均，也难以保证聚合后的全局参数仍具有一致的解释基础。联邦标准化恰好在不暴露原始样本的前提下解决了这一问题，其数学结果与集中式 StandardScaler 等价，但隐私边界更符合联邦学习场景。

目标变量 ContAmnt 在训练前采用 0.25 次幂变换，即四次方根变换。采用这一变换是对 Zhang et al. (2023) 方法思路的直接继承，但本文根据自身数据特征将其纳入联邦训练流程。这样处理的原因在于，合同金额具有明显右偏和长尾特征，若直接在原始金额尺度上最小化均方误差，大额项目会主导梯度方向，模型将更偏向降低少数大型项目的绝对误差，而忽视大多数中小型项目的相对误差控制。四次方根变换通过压缩极端金额的量级差异，使模型在训练中更关注不同规模项目上的相对拟合质量，这与本文以 MAPE 为主指标的评价目标保持一致。模型输出在预测后再通过四次方逆变换恢复到原始金额尺度，以保证结果仍具有工程解释性。

在样本划分上，本文采用“全局分层抽样 + 本地二次划分”的两级方案。首先，在全局层面对客户端标签进行分层抽样，将 688 条样本划分为 550 条全局训练集、69 条全局验证集和 69 条全局测试集。随后，再将全局训练集按客户端归属下发到本地，并分别划分为本地训练集和本地验证集，其中 Client 1 为 148/38，Client 2 为 150/38，Client 3 为 140/36。之所以采用两级划分，而不是只保留一个统一验证集，是因为实验 C 中有两类不同的评价需求：本地验证集用于判断“某个客户端本轮上传的更新是否值得在聚合时赋予更高权重”，全局验证集则用于判断“本轮聚合后的全局模型是否优于历史最佳模型”；测试集则在整个训练过程中保持不可见，仅用于最终性能报告。三类数据承担不同统计任务，能够避免调参与最终评价相互污染。

4.2 联邦模型训练

实验 C 在客户端和服务器端采用同构的多层感知机 CostEstimationMLP 作为基础预测器，其网络结构为 10-128-128-64-32-1，总可训练参数约为 28,993。该结构并非盲目追求复杂度，而是针对当前 688 条样本、10 个输入变量和明显非线性造价关系所作出的折中选择。若网络过浅，则难以表达工程属性与宏观经济因素之间的交互效应；若网络过宽或过深，则在小样本条件下极易过拟合，并放大联邦聚合时的参数波动。因此，这一规模的 MLP 既保留了足够的函数逼近能力，又仍处于可稳定聚合的范围内。

每个隐藏层均采用“Linear + BatchNorm1d + GELU + Dropout(0.1)”的组合，并使用 Xavier 均匀初始化。这里每一个技术点都承担具体功能。BatchNorm1d 的作用是稳定各层激活分布，减轻联邦训练中由不同客户端数据分布差异引起的内部协变量偏移；GELU 相比 ReLU 保留了更平滑的非线性响应，更适合处理经济变量与工程变量共同作用下的连续型回归任务；Dropout 设置为 0.1 而非更大的 0.3 或 0.5，是因为当前网络规模本就不大，如果丢弃比例过高，会直接削弱对有限样本的表示能力，而 0.1 可以提供轻量正则化，配合 weight decay=1e-4 抑制过拟合；Xavier 初始化则有助于在多层前馈网络中保持前向与反向信号的方差稳定，避免联邦训练初期因客户端同步起点不稳而放大收敛波动。

在联邦训练流程上，本地模型与全局模型并不是两套彼此独立的模型，而是同一模型在不同层级上的两种状态表示。每一轮通信开始时，服务器持有当前全局参数 w^(t)，并将其广播给 3 个客户端；各客户端以该参数为初始化，在各自本地训练集上完成若干轮局部优化；局部训练结束后，客户端不上传原始数据，而是上传更新后的模型参数 state_dict 及其在本地验证集上的性能指标；服务器根据预定策略计算聚合权重，对各客户端参数进行加权融合，形成新的全局参数 w^(t+1)，并进入下一轮通信。也就是说，实验 C 中跨节点交换的信息是模型参数与性能摘要，而不是样本本身，这也是联邦学习区别于集中式训练的根本所在。

客户端 k 在第 t 轮的本地目标函数写为：L_k(w)= (1/n_k)Σ_i(f(x_(k,i);w)-y*_(k,i))^2 + (mu/2)||w-w^(t)||_2^2。

式中第一项是变换后目标空间中的均方误差，第二项是 FedProx 近端约束项。实验 C 中 mu 设为 0.01。这个值之所以重要，是因为它直接控制本地模型允许偏离全局参数的程度。若 mu 取 0，则训练退化为纯 FedAvg，本地模型会更容易朝各自区域的局部最优方向快速漂移；若 mu 过大，则又会把本地更新过度拉回全局参数附近，使客户端难以学习自身区域特征。0.01 属于一种弱约束设置，它不会取消本地学习的自由度，但足以在 3 个非独立同分布客户端之间抑制明显的参数漂移，因此更适合当前实验的异质数据结构。

本地优化采用 Adam，基础学习率设为 0.0005，批量大小设为 32，每轮通信中的本地训练轮数设为 20。学习率之所以低于很多集中式表格学习任务中常见的 0.001，原因在于联邦训练中的每次本地更新最终都要进入聚合阶段，学习率过大时，不同客户端间的方向差异会被同步放大，导致聚合后全局模型振荡。批量大小取 32，一方面能够让每个客户端在有限样本下保持足够的梯度更新次数，另一方面也避免了批量过小导致的梯度噪声过强。局部轮数取 20，则是在通信成本与客户端漂移之间做出的折中：若轮数过小，服务器需要更频繁地通信，联邦训练效率下降；若轮数过大，本地模型会更强地吸收局部模式，从而降低聚合的一致性。对于当前 148/150/140 的本地训练样本规模而言，20 轮能够在稳定性和学习充分性之间取得相对平衡。

服务器端的聚合遵循加权平均形式：w^(t+1)=Σ_k alpha_k^(t) w_k^(t+1)，且 Σ_k alpha_k^(t)=1。

实验 C 并未将 alpha_k 固定为单一的样本量比例，而是设置了四类候选聚合策略。size_only 完全按本地训练样本数分配权重，是最接近标准 FedAvg 的基线；perf_only 按本地验证 MAPE 的倒数分配权重，使局部表现更好的客户端在该轮聚合中拥有更高发言权；hybrid 采用样本量权重与性能权重的线性组合，其中 lambda=0.5，表示“统计代表性”和“更新有效性”各占一半；fairness_clip 则在 hybrid 基础上进一步设置 lambda=0.3、alpha_min=0.1、alpha_max=0.6，以防止某一客户端在若干轮内因局部表现领先而长期主导全局模型。之所以设计这四种策略，是因为联邦聚合本质上不是一个纯数学平均问题，而是如何在样本代表性、局部质量和区域公平性之间寻找平衡的问题。实验 C 的调参空间正是建立在这种多目标权衡之上。

需要特别指出的是，原始联邦训练过程中的信息交换并不是“上传梯度、服务器再做一次中心化反向传播”，而是“客户端下载全局参数、本地完成完整优化、服务器聚合更新后的参数”。这一实现细节非常关键。若服务器只收集梯度而不让客户端完成本地若干轮优化，则实验会更接近同步分布式 SGD，而不是本文要研究的横向联邦学习。实验 C 之所以能够体现各区域数据异质性对全局模型的影响，恰恰是因为每个客户端都以相同的初始参数出发，但会在各自数据分布上演化出具有差异性的局部参数状态，再由服务器决定这些差异应如何被吸收进新的全局模型。

Algorithm 1 Multi-Agent System Federated Learning with LLM (MAS-FL-LLM)

Input: client set K={1,2,3}; total communication rounds T=20; base learning rate eta_0=0.0005; base local epochs E_0=20; local train/validation data for each client; global validation and test set on server.

Server executes: initialize global model parameters; for each round t, broadcast global parameters to all clients; collect updated client parameters and local validation metrics; compute aggregation weights according to the chosen strategy; update global parameters; evaluate the aggregated global model on the global validation set; if the current global validation MAPE is the best so far, save the checkpoint; repeat until the final round.

ClientUpdateAndEvaluate: receive global parameters; train the local model on local training data for E^(t) epochs using Adam and FedProx loss; evaluate the updated local model on the local validation set; return updated parameters and local metrics including MAPE, RMSE, MAE and MPE.

4.3 AI-Agent Development (基于大语言模型动态决策的联邦模型优化)

如果说前述联邦训练主线解决的是“如何在不共享数据的前提下协同训练”，那么智能体主线解决的则是“如何让这一协同训练过程不再依赖研究者手工判断”。实验 C 中的智能体系统由三类角色组成。LocalAgent 部署在客户端侧，负责加载当前全局参数、执行本地训练、在本地验证集上计算误差指标并返回更新结果；CentralAgent 部署在服务器侧，负责组织通信轮次、聚合客户端更新、评估全局模型、保存最佳 checkpoint，并在训练结束后执行偏差校正；LLMPlanner 则负责读取最近若干轮训练历史，对下一轮的聚合策略和训练强度给出显式决策。三者构成了“本地执行—全局协调—高层规划”的分层结构。

之所以需要显式引入 LLMPlanner，而不是把聚合规则永久固定，是因为实验 C 面对的是小样本、异质分布和多目标约束同时存在的联邦场景。在这种场景中，最优策略往往不是一成不变的。训练早期更需要稳定收敛，此时样本量驱动的 size_only 或带公平约束的 fairness_clip 更容易保证全局方向不被极端更新带偏；训练中期若客户端之间已经表现出明显的质量差异，则需要让更新更有效的客户端在聚合中拥有更高权重，此时 perf_only 或 hybrid 更有优势；训练后期若性能已接近平台期，则还需要同时考虑误差下降速度与系统偏差方向。单一静态策略无法覆盖这些阶段性需求，因此需要由智能体根据历史状态动态切换。

实验 C 中的智能体决策并不是一开始就完全自由展开的。前 4 轮通信采用强制探索机制，依次执行 size_only、perf_only、hybrid 和 fairness_clip。这样设计的目的，是为 LLMPlanner 提供最初的一组“经验样本”，让它先看到四种策略在当前数据上的真实反馈，再据此开展后续决策。若从第 1 轮开始就让大语言模型在缺乏历史证据的情况下直接决策，那么它只能基于一般性的联邦学习常识作答，而不能真正针对本研究的 3 客户端高速公路造价数据做出有根据的判断。强制探索因此相当于为智能体建立一个小型的在线实验基线。

从第 5 轮开始，CentralAgent 会将最近 10 轮训练历史整理为结构化状态，并提交给 LLMPlanner。该状态至少包含四类信息：一是全局验证集上的 MAPE 和 RMSE，用于刻画全局模型的整体走势；二是各客户端本地验证集上的 MAPE，用于反映局部模型质量差异；三是各客户端样本数和前一轮聚合权重，用于判断样本代表性与权重分配是否失衡；四是上一轮智能体决策及其效果反馈，用于帮助模型识别“上一轮为什么有效或无效”。换言之，LLMPlanner 面对的不是空泛的自然语言提问，而是一份压缩后的联邦训练状态摘要，它的任务是基于这些状态进行策略诊断，而不是直接替代优化器学习参数。

LLMPlanner 在每轮输出三个核心控制量：chosen_strategy_name、lr_scale 和 epoch_delta，并同时生成 reasoning 作为决策解释。其中，chosen_strategy_name 用于在四种聚合方式中选择下一轮策略；lr_scale 用于对基础学习率 eta_0=0.0005 做乘法缩放；epoch_delta 用于对基础本地训练轮数 E_0=20 做加减法调整。为了防止语言模型做出过激控制，系统对输出施加了明确边界：lr_scale 被限制在 0.5 至 2.0 之间，epoch_delta 被限制在 -5 至 +5 之间，最终本地训练轮数 E^(t)=clip(E_0+epoch_delta, 5, 30)。这些边界的存在非常关键，因为智能体在本文中的职责是“受约束地规划训练策略”，而不是无限制地操纵底层训练过程。若没有边界约束，单轮极端决策就可能导致局部漂移失控，直接破坏联邦训练的稳定性。

这种设计使得智能体对联邦模型的调参体现在两个层面。第一层是聚合层面的调参，即通过切换 size_only、perf_only、hybrid 和 fairness_clip 来改变各客户端上传参数对全局模型的影响系数。第二层是训练强度层面的调参，即通过 lr_scale 和 epoch_delta 控制每个客户端在当前轮内的学习步幅和优化深度。前者决定“谁对全局模型说话更大声”，后者决定“每个客户端本轮说话的力度有多强”。在实验 C 中，真正的创新并不只是加入了一个 LLM，而是把这两类原本依赖人工经验的控制量统一纳入一个可记录、可解释、可复用的决策闭环。

从当前数据结构看，hybrid 和 fairness_clip 之所以是非常关键的技术环节，是因为它们最能反映实验 C 的问题本质。当前 3 个客户端样本量虽然接近，但并不完全相同，本地数据质量也会随轮次变化而波动；如果只按样本量聚合，会忽略更新质量差异；如果只按性能聚合，则又可能让某个暂时领先的客户端长期主导全局模型。hybrid 通过 lambda=0.5 在“代表性”与“有效性”之间建立对称折中，适合训练进入稳定下降阶段后的持续优化；fairness_clip 则进一步用 alpha_min=0.1 和 alpha_max=0.6 限制权重极端化，更适合在客户端表现分化明显时保护弱势客户端不被完全边缘化。因此，这两个策略既是技术手段，也是实验 C 中“联邦协同是否公平且稳定”的核心体现。

智能体除了帮助调参，还承担绩效解释功能。每当一轮训练结束后，CentralAgent 不仅记录本轮全局指标和客户端指标，还保存 LLMPlanner 的原始决策及其 reasoning。这样一来，训练过程中的策略切换、学习率调整和本地轮数变化都不会在实验结束后变成无法追溯的“黑箱修改”，而会以结构化日志形式保留在系统中。对方法研究而言，这一点很重要，因为本文不只是要说明联邦模型最后取得了什么结果，更要说明它是如何在训练过程中逐步达到该结果的，以及哪些决策是性能改善的关键触发因素。

4.4 Performance Evaluation and Model Selection

实验 C 的绩效评价采用多指标联合方式，而不是以单一误差作为唯一依据。服务器端在全局验证集和测试集上计算 MAPE、RMSE、MAE、MPE、NRMSE 和 R^2。其中，MAPE 被设定为主指标，因为本研究的目标是提升不同规模项目上的相对预测精度；RMSE 用于识别是否存在少量大偏差样本对模型造成显著影响；MAE 则反映平均绝对偏差水平；MPE 用于判断模型是否存在系统性高估或低估；NRMSE 通过范围归一化便于不同阶段之间进行相对误差比较；R^2 则用于衡量模型对总体变异的解释能力。采用多指标联合评价的原因在于，工程造价预测不仅要看误差大小，还要看误差结构、偏差方向以及模型对不同量级项目的稳定性。

本地验证、全局验证和测试集在绩效评价中的作用严格区分。LocalAgent 输出的本地验证指标用于支持聚合决策，回答的是“谁的更新在本轮更值得被信任”；CentralAgent 在全局验证集上计算的指标用于支持模型选择，回答的是“聚合后的全局模型是否真正变得更好”；最终测试集则仅在训练全部结束并恢复最佳 checkpoint 后调用，回答的是“该方法在未见数据上的最终泛化效果如何”。这种三层评价机制与实验 C 的分层控制逻辑是一致的：局部评价服务于局部贡献判断，全局验证服务于训练过程控制，测试评价服务于结果报告。

在模型选择上，实验 C 采用基于全局验证集 MAPE 的最佳 checkpoint 策略，而不是直接使用最后一轮模型。具体做法是，服务器在每轮聚合完成后都在全局验证集上评估一次当前全局模型，并将验证 MAPE 最低的轮次保存为最佳状态。这样处理的原因在于，联邦训练不同轮次间常常伴随策略切换和权重波动，最后一轮并不必然代表整体最优状态。以验证集最优轮次作为最终模型，能够降低单轮偶然波动对结果报告的影响，也更符合方法研究对统计稳健性的要求。

在最终测试前，CentralAgent 还会在全局验证集上执行一次基于 MPE 的比例偏差校正，其形式为 y_hat_corr = y_hat / (1 + delta)，其中 delta 为验证集上的平均百分比误差。之所以采用比例校正而不是直接加减常数，是因为高速公路项目合同金额的量级跨度很大，系统性偏差更常表现为“整体偏高若干百分比”或“整体偏低若干百分比”，而不是固定金额的平移误差。利用验证集估计这一比例偏差，再将其应用于测试阶段，可以在不重新训练模型的前提下，对全局预测进行轻量后处理，从而提升最终绩效评价的可信度。

综上，实验 C 的方法论并不是若干技术模块的简单叠加，而是一套围绕“隐私受限条件下的跨区域协同造价学习”这一目标而组织起来的完整研究流程。数据处理部分解决的是联邦场景是否真实且输入空间是否一致的问题；联邦训练部分解决的是本地模型与全局模型如何在参数空间中完成稳定协同的问题；智能体部分解决的是聚合策略和训练强度如何依据历史状态动态调整的问题；绩效评价部分解决的是如何在局部表现、全局表现和最终泛化结果之间建立清晰且不混淆的评价边界。也正是在这四个层次上，本文将 Zhang et al. (2023) 的高速公路造价预测思路进一步扩展为一个适用于实验 C 的联邦学习与智能体协同框架。
