# Archive Index

This folder keeps historical project material that is useful for traceability but is not the current source of truth.

## Current Rule

The current experiment pipeline uses `Data/all_Data/Client_Data_Split_Cleaned.csv` and regenerates current outputs under `results/`.

## Historical Material

- `deprecated_reports/`: old progress reports and interim notes.
- `dev_process/`: development process notes and rough analysis drafts.
- `rerun_backup_2026-05-24/`: historical outputs preserved before the current rebuild.

Files in `archive/rerun_backup_2026-05-24/results/` can be used for comparison only. They should not be cited as the final result after this rebuild unless they are explicitly copied into `results/` by a rerun or a documented recovery step.
