# 基线模型总结

## 概述

为联邦学习实验建立了两个集中式训练基线：
- **场景A (GBR)**：sklearn模型的性能上限
- **场景A-Prime (NN)**：神经网络的性能上限

---

## 性能对比

| 场景 | 模型 | MAPE | RMSE | R² | 用途 |
|------|------|------|------|----|----|
| **场景A** | GBR | **46.88%** | **$1,719,370** | **0.54** | 绝对上限 |
| **场景A-Prime** | PyTorch MLP | **49.58%** | $3,114,967 | -0.52 | NN基线 |

**差距：** 2.70% MAPE

---

## 场景A：GradientBoostingRegressor

### 配置
```python
{
    'n_estimators': 200,
    'learning_rate': 0.1,
    'max_depth': 5,
    'subsample': 0.8
}
```

### 性能
- **测试集MAPE**: 46.88%
- **验证集MAPE**: 44.06%
- **R²**: 0.5379
- **预测范围**: 完全在训练范围内（无极端值）

### 优势
- 表现最佳
- 训练快速（<1秒）
- 稳定可靠
- 无需调参

### 文件
- 模型：`results/models/centralized_gbr_model.pkl`
- 结果：`results/centralized_results.csv`
- 预测：`results/centralized_predictions.csv`

---

## 场景A-Prime：PyTorch MLP

### 配置
```python
{
    'architecture': [10, 64, 32, 1],
    'dropout': 0.1,
    'learning_rate': 0.001,
    'weight_decay': 0.0,
    'batch_size': 32
}
```

### 性能
- **测试集MAPE**: 49.58%
- **最佳验证loss**: 0.308
- **训练轮数**: 179 (早停)
- **预测范围**: 1个超出训练范围

### 优势
- 接近GBR性能（差距仅2.7%）
- 为联邦学习提供公平对比
- 与场景B/C使用相同模型架构

### 文件
- 模型：`results/models/centralized_nn_model.pth`
- 结果：`results/centralized_nn_results.csv`
- 预测：`results/centralized_nn_predictions.csv`

## 为什么需要两个基线？

### 场景A (GBR) - 绝对性能上限
- 回答："在集中式训练下，能达到的最佳性能是多少？"
- 作用：证明数据质量良好，任务可行
- 与sklearn模型对比时使用

### 场景A-Prime (NN) - 神经网络上限
- 回答："联邦学习使用的神经网络，集中式训练能达到多少性能？"
- 作用：公平评估联邦学习的影响
- **与场景B/C对比时使用**（关键！）

## 关键洞察

### 1. 神经网络可以达到好性能
- 49.58% vs 46.88%，差距仅2.7%
- 证明NN架构本身是合适的
- 问题不在模型，而在训练方式

### 2. 树模型仍有优势
- 在表格数据上GBR天然更优
- 但NN的表现已经足够好
- 49.58%的MAPE在实际应用中可接受

### 3. 超参数调优的重要性
- 从MAPE 117%（原始）→ 49.58%（调优后）
- 最佳配置：dropout=0.1是关键
- 证明了全面搜索的必要性
